# Sports Schedule Share App

Shareable sports schedule app for Cardinal Charter Academy Volleyball and future teams.

This frontend uses the existing Supabase `schedule-api` Edge Function for public schedule viewing, administrator edits, calendar subscription, and administrator recovery.

## Deploy

Import this repository into Vercel as a static site. No build command is required.
